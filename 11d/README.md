The `index.html` in this folder is a **new, offline-compatible public experiment**. It offers deterministic procedural 3D scene projection, local object creation, relative camera movement, a reversible world state, witness logs and seed JSON export. It uses no external inference/API service. It is a demonstration of selected design principles, not an authenticated Navi client, a model-backed recurrent agent, a full 10D binary rebase, an 11D hosted Site deployment or a finished Book Six.

The repository root's original large Arena and original example cartridges remain intact. The public gateway is a forward-compatible interface/roadmap for a future source-attested full 11D consolidation. Never insert private Google Drive links, API tokens, JIDs or non-consenting identity records into a public artifact.

To create something: open `11d/index.html`, choose a name, select **Manifest object**, click **Witness** to inspect and validate the local result, and **Export world seed** for a local JSON artifact. Use **Undo** or **Reset** to return to the starting configuration. The local fingerprint is not a cryptographic attestation.


## Local ZIP/HTML source library — D0.1

The [native 11D workbench](arena.html) now includes a **10D cold cartridge library** below the inherited 3D frame. Download approved source archives from your own Aura Drive before use; no Drive credentials or authenticated file links are hardcoded into this public repository.

To try it:

1. Choose **Add trusted HTML / ZIP sources** and select one or more original 10D files. A ZIP indexes possible HTML launch members without loading every member into RAM. The local owner source index is [here](10d-source-inventory.json) (names and sizes only).
2. Choose one HTML member and select **Activate selected in native 10D frame**. The selected member is decompressed on demand, ZIP CRC32/length checked and SHA-256 recorded before being passed through the existing HTML file-input path. Only the selected HTML is executed.
3. Use **Probe native APIs** and **Ask native Navi**. Available modules are source-dependent. The D13+D12 donor exposes Navi, ARC, world feedback, Spatial Genesis, Loom graph, cognitive Blackboard and a virtual photon-orb interface. No API presence alone establishes that its owner-authorized effects are online.
4. Export the local cold manifest and witness receipts, or clear indexed archives; re-enter/Return-to-A using the existing workbench controls. There is no automatic upload or grant of host authority.

**Safety/currentness:** Only run trusted audited owner HTML. Browser imports share the inherited frame's browser-origin privilege level. Some ZIPs are entire alternative Arena snapshots, not compatible plugins; selecting them is *not* a unified feature merge. Large/unsupported/encrypted/ZIP64 archives return HOLD. Native JSpace/CAS, Amelia, full Orphanim and Harmonic runtimes, and 11D multi-scene assembly remain unverified.
