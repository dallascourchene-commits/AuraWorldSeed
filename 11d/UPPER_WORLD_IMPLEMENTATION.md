# 11D federated upper-world D0.1 (Parallax candidate)

This change is **additive** to the pre-existing public 11d world-builder. The original 54 MB root Arena, cartridges, game, benchmark programs and GitHub main remain unchanged.

### Functional public surfaces
* Synthetic Orphanim: 24 individually routable gates, central pulsing witness (not physical optics).
* Harmonic model: adjustable two-source phasor interference, local witness receipts.
* K27: explicit 27^9 logical address scale, three sparse symbolic routes, exact local reopen. Hash routing is NOT meaning-based retrieval.
* Four-role workcell: author proposal, challenger approval or denial, verifier validity gate, rebaser commit and reversible return-to-A. Browser-local control, NOT independent LLM workers.
* Navi: safe read-only index of publicly available AuraWorldSeed capability and source links, with named capability status and source location.
* Native: explicit, lazy launch of preserved full root Gem, without importing its private inference or host state.

### Boundaries
This is **not a complete accepted 11D rebase** or authenticated private Drive Navi / Amelia Virtual Terminal. The connected owner Site and its hosted MCP remain separate from public GitHub Pages. Do not expose private Google Drive files, user credentials, JIDs, machine tunnel configuration or keys in source.
The 10D Gem Arena folder holds a large historical collection, with divergent branches and unpromoted prototypes. Source presence is not acceptance. Full source attestation, in-Arena Navi tool execution, model-backed observer instances, native 3D scene co-presence, ACL-controlled Blackboard, and runtime-scale tests remain integration gates.

### User acceptance path
Open 11d/index.html in Chrome. In a browser console, run Aura11D.health(). Route a K27 intent, then reopen its cold locator. In Workcells, try a denied commit, an allowed-and-verified commit, and Return to A. Open Navi, search Orphanim. In Native, optionally launch the large original Arena; check native readiness within that Arena itself.
