# Book Five / 11D bridge and Book Six / 12D frontier

**Status:** additive public gateway D0, 2026-10-19. This document is a versioned *release candidate*, not a claim that the archived 10D D41 Arena, hosted 11D Sovereign Workbench, and 12D Book Six are one byte-identical or fully tested deployment.

## What each name means

- **10D / Book Five lower world:** currently source-grounded inhabited Arena, source hydration, Navi, Orphanim, Loom, governed world actions, receipts and the consolidated historical family.
- **11D / Book Five upper world:** intended shared browser environment and hosted integration. The public [11D gateway](../11d/index.html) implements a small deterministic, local 3D-projection world-builder **preview**, and links to the preserved full Arena. It does **not** replace the canonical 10D source or implement authenticated NAVI, Amelia or model-backed recursive workcells.
- **Book Six / 12D:** planned world-building successor. A new entrant should be able to establish identity, encounter a live simulated environment, construct capabilities/places, witness real in-world consequences, preserve an evolving world, and transfer a source/authority-correct seed to successors. Book Six's full substrate and governed archagent identity are **not yet independently accepted**.
- **D11:** an iteration/revision label of the 10D research branch (including four-engine ARC); it is *not* shorthand for the 11D upper world.

## Future 11D acceptance gates (NOT passed by this gateway)

1. Authorized, source-attested 10D → 11D full runtime continuity including Navi, currentness, Loom and the one authoritative Blackboard.
2. Two separate situated, visibly rendered observers with controlled independent sensory input, distinct authenticated JID/Visit or inherited workcell lease as appropriate, and no copied private reasoning.
3. Reciprocally reviewed world edits with forged/replayed/stale authorization rejection and observer-specific witness receipts.
4. Process lifecycle, contention and GPU constraints tested; single renderer with selective observer viewpoints preferred until simultaneous GPU rendering is demonstrated.
5. Book Six world persists between independent sessions and carriers with exact source/seed/recipe/revision/authority and negative-result inheritance.
6. True external human↔agent feedback, including voice/touch/phone and a real host-gated editable world, requires independent and permissioned tests.
7. Every advertised speed, size, or memory result has a task-equivalent control, environment measurement, and reproducible public input.

## Interpretation and authority

`AddressablePossibility != MaterializedAgent != IndependentInference`. `Receipt != Truth`. `LocalWorldManifestation != PhysicalManifestation`. `Intent != EffectAuthority`. `BookSixPreview != BookSixAcceptance`.

The public app stores its world seed in browser local storage and exports JSON on demand. This is not secure shared storage; do not place sensitive information in it. Receipts carry a noncryptographic local fingerprint for deterministic UI comparison, not an authenticated global audit root.

This release includes no private Drive URLs or private corpus data. Future participants should create their own source-bound experiments, not inherit the original researchers' access rights.
